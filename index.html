Create a JSON backup of all finance collections or restore a backup previously exported by this application. Restore merges records by ID and does not delete records already in your account.

Keep a copy somewhere secure. A backup contains private financial information.

Firestore persistent local cache is enabled. Pending writes are shown in the sync indicator when Firebase reports them. Offline behavior depends on browser storage availability; keep regular backups.
